# กฎการทำงานสำหรับ LIKA Research Helper (Steering Rules)

- **โครงสร้างแอปพลิเคชัน:** ต้องสร้างเป็นเว็บแอปพลิเคชันไฟล์เดียว (`index.html`) ที่รวม HTML5, Tailwind CSS และ Three.js (r128 ผ่าน CDN)
- **ขอบเขตเนื้อหา:** เน้นสาขาวิชาวิจัยหลักของมหาวิทยาลัยมหิดล วิทยาเขตกาญจนบุรี (ธรณีศาสตร์, ชีววิทยาอนุรักษ์, นวัตกรรมอาหาร, วิทยาศาสตร์การเกษตร, วิศวกรรมสิ่งแวดล้อม, การบริหารธรุกิจ, บัญชี, บริหารงานบุคคล, ครุภัณฑ์และพัสดุ )
- **มาตรฐานวิชาการ:** การอ้างอิงแทรกในเนื้อหา (Inline Citations) ต้องใช้รูปแบบ [ผู้แต่ง et al., ปี ค.ศ.] (เช่น [Srisuwan et al., 2024])
- **ธีมการออกแบบ:** ใช้โทนสีน้ำเงินมหิดล Mahidol Royal Blue (#002366), พื้นหลังสีมืด Dark Slate และกรอบข้อความสไตล์ Glassmorphism UI
