# ข้อกำหนดคุณลักษณะ (Spec): Challenge 3 - ผู้ช่วยทบทวนวรรณกรรมและงานวิจัย (Research & Lit-Review Helper)

## เกณฑ์การยอมรับผลงาน (Acceptance Criteria)
1. **การโหลดข้อมูลหลายเอกสาร (Multi-Paper Ingestion):** โหลดข้อมูลตัวอย่างงานวิจัยของวิทยาเขตกาญจนบุรี (MUKA) ล่วงหน้าอย่างน้อย 3 ฉบับ
2. **กราฟความรู้ 3 มิติแบบมีปฏิสัมพันธ์ (3D Interactive Knowledge Graph):** แสดงผลเครือข่ายด้วย Three.js พร้อมโหนดที่กดคลิกได้ (โหนดสีทอง = งานวิจัย, โหนดสีฟ้า Cyan = ระเบียบวิธีวิจัย)
3. **ตารางเปรียบเทียบระเบียบวิธีวิจัย (Comparative Methodology Matrix):** ตารางเปรียบเทียบครอบคลุม 5 ประเด็น คือ วัตถุประสงค์, ชุดข้อมูล/กลุ่มตัวอย่าง, ระเบียบวิธีวิจัย, ผลการศึกษาสำคัญ และข้อจำกัด
4. **ร่างบททบทวนวรรณกรรมที่แก้ไขได้ (Editable Literature Review Draft):** ย่อหน้าสังเคราะห์เนื้อหาอัตโนมัติพร้อมการอ้างอิงแทรกในข้อความ [ผู้แต่ง, ปี] และปุ่มส่งออกการอ้างอิงรูปแบบ APA
